version 2.0.0 - September 7th, 2026

- Major version update
  - NOTE: Version 1.x hardware will _not_ work with this release. Use a version 1.x firmware release for updates.

- Totally revised hardware
- Now a 6hp module
- Using DAC7554 for DAC outputs
- Using a rotary encoder for input
- Split board design with a main PCB and an IO PCB
- Better signal handling on the board with better component layouts
- Able to add MCM-100-EX expansion module for four additional CV outputs

- Almost totally revised software
- Redesigned menu and dashboard system
- More responsive and better MIDI message handling.
- Fully routable CV outputs - send any event to any of the assignable CV outputs
- Clock divisions! Process every clock tick down to every 96 clock ticks (4 frames worth)
- Stability and optimization updates across the board
